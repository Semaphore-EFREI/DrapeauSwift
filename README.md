#  Drapeau Swift

Drapeau est la bibliothèque SwiftUI définissant l'interface utilisateur de Sémaphore sur iOS, iPadOS, macOS et watchOS.

Ne pas oublier d'appeler FontLoader.registerFonts() au démarrage de l'app (sinon erreur à cause des polices)
